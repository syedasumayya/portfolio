# Syeda Sumayya Zahid — Portfolio

A personal portfolio site for showcasing my work across AI, computer vision, robotics, and full-stack development — built as a dark, glassy, tech-themed single-page-feel app with animated backgrounds, an interactive hero, and real project data pulled from my own GitHub.

**Live site:** https://sumayya-portfolio.vercel.app/

---

## About

I'm a Software Engineer and Builder who works across full-stack & mobile development, AI/ML, computer vision, and robotics (ROS 2). This portfolio brings all of that together in one place — my background, my projects, my skills, and a way to get in touch.

## Features

- **Animated background** — a canvas-based particle network with glowing nodes, traveling pulses, and a mouse-reactive spotlight, plus a persistent animated scan-path overlay behind every section
- **Interactive hero** — a click-to-activate orbiting-icons constellation around a central badge, with a full-page flash animation on activation
- **Multi-page routing** — dedicated routes for Home, Projects (list + detail pages), and more
- **Projects deck** — a click-to-advance card deck with real project data, generated per-project visual art, and GitHub links
- **Live GitHub repositories** — fetches and displays my latest public repos directly from the GitHub API
- **Skills, Experience & Education** — color-coded, animated sections with expandable details
- **Contact form** — submits directly to my inbox via Formspree, with a live visit counter
- **Fully responsive** — built mobile-first with Tailwind

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/syedasumayya/portfolio.git
cd portfolio
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

### Build for production

```bash
npm run build
npm start
```
## Deployment

This project is deployed on [Vercel](https://vercel.com/). Pushing to `main` triggers an automatic deployment.

To deploy your own copy:

1. Fork or clone this repository
2. Import it into Vercel
3. Vercel auto-detects the Next.js config — no extra setup needed
